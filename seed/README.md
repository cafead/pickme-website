# seed/

A website backup `.zip` placed here is used automatically when the site starts with an empty data folder (a fresh install). An existing site shows "Use the backup" at the top of admin instead.

This repository is public, so only put a **website backup** here (menu, texts, photos). Never a full backup: those contain orders and customer phone numbers.

The live site keeps its data on the Railway volume at `/data`, so normally this folder stays empty.
